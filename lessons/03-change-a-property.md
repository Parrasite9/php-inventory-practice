# 03 · Change one object's value

**Start:** `$bolts` exists, and you can display its quantity.

**File:** `inventory.php`, after the class definition, where you created your objects.

Example with an unrelated object:

```php
$lamp->brightness = 50;
```

This changes a property on that particular object. It does not change the class definition.

**Your turn:** set the quantity on `$bolts` to `15`. Choose a location that makes your existing quantity output display the new value.

Run the file and share your attempt. If it still displays `10`, consider the order of the lines.

After review, change it to `8` and predict the output before running.
