# PHP inventory practice — from an empty file

**Start with [Lesson 00](lessons/00-start-an-empty-file.md). Read only that lesson for now.**

You create `inventory.php` yourself. No application code is supplied. Each short lesson teaches one piece of the setup before asking you to use it.

Requires PHP 8.1 or newer. No packages, database, or web server. Open this folder in Cursor; the first lesson explains creating and running your file.

You will build the file, class, properties, and methods gradually. Later, you will create a second PHP file and connect the two. Each run starts fresh; nothing is saved between runs.
