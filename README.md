# PHP inventory practice

Learn objects, properties, methods, and arguments by building a tiny inventory tracker.

**Start with [Lesson 01](lessons/01-create-an-object.md). Only read that lesson for now.**

## Run your code

Requires PHP 8.1 or newer. No packages, database, or web server.

Open `inventory.php` in your editor. From this folder, run:

```bash
php inventory.php
```

Each run starts fresh. Nothing is saved between runs.

## What is provided

One small `Item` class. You write the practice code and add behavior gradually. The startup message only confirms execution, not correctness.
